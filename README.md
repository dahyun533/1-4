# 1-4(mission4) 기능을 더하고 확인·복구를 반복하기

코디세이 AI 네이티브 입학연수과정 미션4 제출물.

- **미션:** 새 기능을 더하고, 완성 기준으로 확인한 뒤 고치거나 원래 파일로 돌아감.
- **한 것:** 카드에 한 줄 메모 달기 기능 추가. '인생 영화', 'n차 관람' 같은 메모를 달고 싶어서 고름.
- **결과:** 첫 파일에서 메모 정렬과 칸 크기 문제를 찾아 한 번 고쳐 완성.
- **완성본:** `html/영화_기능추가_수정1.html`

## 파일 이름 규칙

- 폴더 안은 `html/`(페이지), `md/`(기획서·기록), `대화 캡처/`(AI와 나눈 주요 대화)로 나눔.
- 대화 캡처는 `AI이름_대화캡처번호.png`로 저장. 예: `claude_대화캡처1.png`, `chatgpt_대화캡처1.png`.
